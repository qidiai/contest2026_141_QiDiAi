## 补充评测（三速池 + OOV + 长文本）

### 1. 三速池实测

V9v3 存在 fast/medium/slow 池共线退化（cosine=1.0）。V10 通过 `(1-decay)` 缩放因子修复。

| 测试 | 结果 |
|------|------|
| "hello" vs "hello world test long text here" | cosine=0.8493 |
| 判定 | **PASS** — 池未退化 |

## 结论

V10 全面优于 V9v3，推荐作为正式参赛引擎。在 200 条语料规模下，recall@3 达到 100%，三速池未退化，OOV/emoji 全部通过，完全满足可穿戴设备离线语义搜索需求。
